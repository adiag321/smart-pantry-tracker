# data/

Populated by the weekly GitHub Action (`.github/workflows/scraper.yml`),
which commits `walmart_data.csv`, `heb_data.csv`, and an append-only
`price_history.csv` here after every run. Empty until the workflow runs for
the first time - see [`scripts/scraper/README.md`](../scripts/scraper/README.md)
to run it locally sooner.
